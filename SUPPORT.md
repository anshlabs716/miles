# Support

## Getting help

- **Documentation** — start with [README.md](README.md) and the
  [`docs/`](docs/index.md) directory.
- **Bug reports** — open an issue using the *Bug report* template.
- **Feature requests** — open an issue using the *Feature request* template.
- **Questions** — open an issue using the *Question* template.

## Before opening an issue

1. Make sure you are on the latest version.
2. Search existing issues to avoid duplicates.
3. Check [docs/troubleshooting.md](docs/troubleshooting.md).

## What to include

- Operating system and version
- MILES version
- Exact steps to reproduce
- Expected vs. actual behavior
- Relevant logs or screenshots

## Security issues

Do **not** open a public issue for security problems. See
[SECURITY.md](SECURITY.md).
