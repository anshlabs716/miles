# Third-Party Notices

MILES is built with and depends on third-party software. This file lists the
major components and their licenses. It is provided for attribution and is not
legal advice.

## Dependencies

- **Kotlin** — application language
- **Jetpack Compose** — UI toolkit
- **Material 3** — design system
- **Room** — local database
- **AndroidX** — platform libraries
- **OpenStreetMap** — map data
- **Health Connect** — optional activity data integration
