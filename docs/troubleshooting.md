# Troubleshooting

This page collects common problems and their solutions. If your problem is not
listed here, open an issue using the bug report template.

## Build or install fails

- Confirm you meet the requirements in the [README](../README.md).
- Update your toolchain to the version stated in the project configuration.
- Delete any local build cache and try again.

## The application does not behave as expected

- Make sure you are on the latest version.
- Reproduce with a clean state and note the exact steps.
- Attach logs or screenshots (remove private data first).

## Still stuck?

Open an issue with your operating system, version, and reproduction steps.
