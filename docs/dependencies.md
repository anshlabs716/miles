# Dependencies

This page lists the main third-party components used by MILES and what each
one is for. See [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) for
attribution.

- **Kotlin** — application language
- **Jetpack Compose** — UI toolkit
- **Material 3** — design system
- **Room** — local database
- **AndroidX** — platform libraries
- **OpenStreetMap** — map data
- **Health Connect** — optional activity data integration
